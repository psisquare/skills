# Slide-time budget reference

> Use this to compute slide count and per-slide duration before drafting the brief.
> Build the time-budget table in §2 first. Slide count × time-per-slide must equal total duration.

## Time-per-slide-type defaults

| Slide type | Default minutes |
|---|---|
| Title | 0.5 |
| Frame ("why we're here") | 1.5 |
| Background / context | 2 |
| Agenda | 1 |
| Why now | 3 |
| Scope (in / out) | 2 |
| End-to-end diagram | 6–8 |
| Sub-diagram (zoom into one part) | 3–4 |
| Comparison (2–3 options) | 4–5 each |
| Conflict / open question | 3–5 each |
| **Live-fill grid (primary deliverable)** | **12–20** |
| Decision capture (vote, ranking) | 8–12 |
| Way of working / process | 3 |
| Timeline (phases, no dates) | 2 |
| Roadmap (phases, with dates) | 4–6 |
| Risk register | 4 |
| Asks / next steps | 2–3 |
| Close | 2 |

Buffer: always allocate 2–4 min for slack.

## Quick formulas by duration

### 30-min session
- 6–8 slides
- One primary discussion topic
- ≤ 1 diagram slide

### 45-min session
- 9–11 slides
- 1 diagram + 1 decision

### 60-min session (most common)
- 12–15 slides
- 1 background slide + 1 diagram + 2–3 conflict/option slides + 1 live-fill grid + 1 way-of-working + 1 close

### 90-min session
- 16–20 slides
- Multiple decisions + more diagram drilldown

### 120-min session
- Break into 2 logical halves with a mid-session break slide
- Cap at 25 slides — beyond that, deck becomes a document

## Pacing rules

1. **No slide ≥ 20 min.** If a topic needs more, split it into 2 slides (frame + drill).
2. **No slide ≤ 30 sec** unless it's a title or close. If a thought takes < 30 sec to state, merge it with adjacent slide.
3. **Live-fill grid is the load-bearing slide.** Give it the most time. Everything else compresses around it.
4. **Buffer is sacred.** Don't fill it. Sessions always run long on the discussion slide.

## Common mistake: pre-read assumption

If audience has NO pre-read, add 2–4 min for Background slide (Slide 3 pattern). Do not assume context.

If audience HAS pre-read, you can skip Background and tighten Why-now to 1–2 min.

State pre-read status in §2 frame table. The slide count + time budget downstream depend on it.

## Common mistake: too many conflict slides

If source has 5+ conflict examples, do not put all 5 in main deck. Pick 2–3 for main, push the rest to appendix slides (numbered 16+, only used if time permits). The brief should explicitly mark them as appendix.
